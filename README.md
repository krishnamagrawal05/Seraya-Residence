# Seraya Residence — Island After Dark

A cinematic, single-page website concept for a private island residence in the Indian Ocean. Built around quiet mornings, ocean light, warm evenings and unhurried days.

**🌴 Live demo:** [seraya-residence.netlify.app](https://seraya-residence.netlify.app)

> This is a frontend demo. All rates, products, activities and island conditions are sample content. The booking form does not confirm reservations or collect payment.

---

## Overview

Seraya Residence is a design-led resort concept with a dark, cinematic look: a full-screen video hero, editorial typography and smooth scroll storytelling. The site walks visitors from the island's story through stays, experiences, dining, wellness and a sample stay planner.

## Features

- **Cinematic hero:** looping resort video with a sound toggle
- **Residences:** four villa types with a side-by-side comparison table
  - Ocean Garden Villa: $680 / night
  - Beachfront Pool Villa: $920 / night
  - Sunset Residence: $1,280 / night
  - Seraya Grand Residence: $1,850 / night
- **A day at Seraya:** a timeline from sunrise breakfast to cinema under the stars
- **Experiences:** reef discovery, sunrise kayak, jungle walk, yoga and more
- **Wellness and games:** a wellness menu and an evening games pavilion
- **Dining at Tide House:** breakfast through dessert, plus a zero-proof sunset bar
- **Celebrations:** pick a mood (birthday, anniversary, private dinner, private event) and get a sample concept
- **Interactive island map:** click a location to change the photo, description and details in the panel
- **Gallery:** image grid with a larger lightbox view
- **Journal:** short stories from the island
- **Stay planner:** choose a residence, dates and add-ons to see an illustrative total
- **Sustainability and arrival journey:** the concept's values and a four-step arrival sequence
- **Concept shop:** an "add to bag" store with a live bag counter
- **Island conditions:** sample air, sea, wind and sunset data (not live weather)

## Getting Started

Clone the repository and open it locally:

```bash
git clone https://github.com/<your-username>/seraya-residence.git
cd seraya-residence
```

Open `index.html` in your browser, or serve the folder with any static server:

```bash
# Python
python3 -m http.server 8000

# or Node
npx serve .
```

Then visit `http://localhost:8000`.

## Deployment

The site is a static frontend and is deployed on [Netlify](https://www.netlify.com/). To deploy your own copy:

1. Fork or clone this repository.
2. Log in to Netlify and choose **Add new site → Import an existing project**.
3. Select your repository. No build command is needed; publish the root directory.
